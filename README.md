# BPPA Official Website

Build a premium, international-standard, responsive official website draft for Bangladesh Para Pickleball Association (BPPA), a para pickleball sports association in Bangladesh.

IMPORTANT: Use the uploaded BPPA logo as the official branding reference. Follow its dark green, white, and lime green color palette. Create a polished, modern sports federation website suitable for presenting the association to international sports organizations, athletes, sponsors, and the public.

DESIGN:
Create a professional, visually impressive homepage with a clean navigation bar, logo, English/Bangla language switcher, hero section, About BPPA, Para Pickleball introduction, programs and events, athlete highlights, news and media, partners, and footer. Use high-quality, respectful, inclusive adaptive sports and pickleball imagery. Make the design responsive for desktop, tablet, and mobile. Avoid generic template styling and excessive animations.

PAGES:
Create separate pages for Home, About BPPA, Para Pickleball, Athletes, Events, News & Media, and Contact. Use reusable components and consistent branding.

BILINGUAL SUPPORT:
Support English and Bangla throughout the entire website. English is the default language. Add a visible language switcher. Translate navigation, headings, buttons, and static content. Keep the structure ready for bilingual news and event content. Do not use automatic machine translation as a substitute for verified official translations.

CONTENT ACCURACY:
This is a preliminary design draft. Do not invent official leadership names, affiliations, recognition, achievements, sponsors, contact details, or organizational history. Use clearly labeled demo content and placeholders wherever official information is unavailable.

TECHNOLOGY:
Use React, TypeScript, and Tailwind CSS. Write clean, modular, understandable code with reusable components, semantic HTML, accessible color contrast, and SEO-friendly page structure.

SCOPE:
For this first phase, build a frontend prototype only. Do not connect a database, authentication, paid APIs, or backend yet. Keep the architecture ready for a future Supabase backend, secure admin dashboard, image uploads, and content management system.

Prioritize excellent visual quality, responsive layouts, fast loading, accessibility, and a credible international sports association identity. Start by building the complete homepage and navigation, then create the supporting pages.
